# Glossary

- **Hard limit**: A non-negotiable minimum or maximum for a nutrient. A plan that violates one is not a valid result.
- **Allergy exclusion**: Removal of catalog foods tagged with a declared allergen. Catalog tags do not establish cross-contact safety.
- **Soft target**: A desired nutrient range used to rank otherwise valid plans. A miss is allowed only with a warning.
- **Feasible plan**: A complete set of meals that passes every allergy, data, hard-limit, and supplied-budget check.
- **Infeasible**: The available, sufficiently sourced choices were evaluated and none meet all hard constraints.
- **Unavailable**: The planner cannot evaluate a required constraint because the necessary source data is missing or unverified, such as price data for a supplied budget.
- **Plan provenance**: Catalog and food-record versions, source records and editions, and algorithm version needed to trace a result.
